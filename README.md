# Trazos

Mini web para pintar trazos con el dedo, el Apple Pencil o el ratón, y exportarlos a **SVG** (un `<path>` por trazo, hoja 3508×2481) o **JSON**.

Dirección: https://lospiestorcidos.github.io/trazos/

- Zoom (pellizco, botones ＋/－, rueda) y mover la hoja (dos dedos o botón ✋ Mover).
- Deshacer, rehacer, grosor, presión y guardado automático en el navegador.
- Funciona sin Internet: abrirla una vez con conexión y «Añadir a pantalla de inicio».
- Para publicar un cambio, sube el número de `VERSION` en `sw.js`.
